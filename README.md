# Chess-Engine

A web-based chess engine and game interface built with JavaScript, HTML, and CSS.

## Overview

Chess-Engine is an interactive chess application that brings the classic game of chess to the web. It provides a full-featured chess board interface where players can enjoy the game with a built-in AI opponent.

## Features

- **Interactive Chess Board**: Clean, intuitive interface for playing chess
- **AI Opponent**: Play against an intelligent chess engine
- **Web-Based**: Play directly in your browser with no installation required
- **Responsive Design**: Works across different screen sizes

## Tech Stack

- **JavaScript** (71625 bytes) - Game logic and AI engine
- **HTML** (12204 bytes) - Page structure and board layout
- **CSS** (713 bytes) - Styling and visual design

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/PR3S1D3NT/Chess-Engine.git
   ```

2. Open `index.html` in your web browser

3. Start playing chess!

## Usage

- **Move Pieces**: Click on a piece to select it, then click on a valid destination square
- **Game Reset**: Use the interface controls to start a new game
- **AI Opponent**: The engine will automatically respond to your moves
